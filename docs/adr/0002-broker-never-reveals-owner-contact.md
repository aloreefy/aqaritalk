# The broker never reveals a property owner's contact details

Owner contact (users.phone via properties.createdBy) is monetized behind the Contact Release dual-gate: both parties must acknowledge commission terms before either sees a phone number. The broker therefore has no tool that returns owner contact, and its prompt must not promise it. Instead, the property card carries a «طلب التواصل مع المالك» action that routes into the existing app contact-release flow. The obvious alternative — an agent tool returning the owner's phone — was rejected because it would let any buyer bypass the commission gate by asking the chatbot. The conversational version of this flow (agent-guided commission acknowledgment in chat) is deferred to the Booking Composer round. The customer-service contact card (get_contact_info, company support details from env config) is unrelated to this rule and stays ungated.
